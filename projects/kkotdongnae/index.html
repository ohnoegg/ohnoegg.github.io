꽃동네

흩어진 꽃집 정보를 한곳에 모아 지역이나 매장명으로 찾는 모바일 탐색 프로토타입

담당팀 리딩 · 서비스 기획 · 에이전트 연동 설계

서비스 · 링크 미등록 GitHub · 링크 미등록
  • Flutter 공식 홈페이지 (새 탭)
  • Django 공식 홈페이지 (새 탭)
  • PostgreSQL 공식 홈페이지 (새 탭)
  • LangChain 공식 홈페이지 (새 탭)
  • Docker Compose 공식 홈페이지 (새 탭)

상황

꽃집 정보가 소셜 미디어와 지도 앱에 흩어져 있었습니다. 지역명으로 검색할 때는 같은 단어가 상호에 들어간 다른 지역 매장도 결과에 섞였습니다.

과제

3인 팀의 리더로서 매장 정보를 한곳에 모아 지역이나 상호로 검색하는 모바일 프로토타입의 범위를 정하고, 대화형 탐색의 연동 구조를 설계했습니다.

실행

  • 팀 조율과 에이전트 설계. 요구사항과 일정을 관리하고, LangChain 에이전트가 Tool Calling과 MCP (Model Context Protocol)로 backend의 매장 조회 기능을 호출하는 구조를 설계했습니다.
  • 매장 데이터와 검색 기준. 팀은 소상공인시장진흥공단의 상가 정보에서 꽃집의 상호·주소·좌표를 추렸습니다. 검색어와 일치하는 행정구역이 있으면 해당 지역의 매장을 반환하도록 검색 기준을 바꿨습니다.

결과

팀은 서울·경기·인천 83개 시·군·구의 꽃집 9,901곳을 검색할 수 있는 모바일 프로토타입을 만들었습니다. 같은 데이터로 변경 전후의 ‘수원’ 검색을 비교했을 때, 처음 50개 결과 중 수원에 위치한 매장이 48곳에서 50곳으로 늘었습니다.
