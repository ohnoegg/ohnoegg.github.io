꽃동네

흩어진 화훼 매장 정보를 연결하고, 에이전트로 탐색을 돕는 플랫폼

담당팀 리더 · 서비스 기획 · 에이전트 설계 및 구현

  • Docker Compose 공식 홈페이지 (새 탭)

해결하려는 문제

화훼 상품을 구매할 때 매장 정보가 소셜 미디어와 지도 앱 등 여러 채널에 흩어져 있어 탐색 비용이 커지는 문제를 발견했습니다. 매장 정보를 한곳에 연결하고, 에이전트 기반 interface로 탐색 경험을 개선하고자 했습니다.

담당 역할과 구현 과정

  • 기획과 팀 리딩. 3인 팀의 리더로 요구사항과 일정을 관리했습니다. 개발 기준을 공유하고 각자의 작업이 연결되는 부분을 조율하며 서비스 구현을 이끌었습니다.
  • 전국 단위 매장 정보 활용. 공공데이터포털의 소상공인 데이터셋을 확보하고, 매장의 위치와 상세 정보를 서비스 탐색에 활용했습니다.
  • 에이전트와 backend 연계. LangChain을 기반으로 Tool Calling과 MCP (Model Context Protocol)를 활용하는 서비스 구조를 설계·구현하고, 에이전트를 backend의 API (Application Programming Interface)와 연결했습니다.

경험과 배운 점

에이전트 기능 구현과 팀 운영을 함께 맡으며 기술적인 연결 지점과 협업의 연결 지점을 모두 다뤘습니다. 요구사항을 구체화하고 팀원과 개발 기준을 맞추는 소통·협업 역량을 키웠습니다.
