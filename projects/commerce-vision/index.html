상품명을 모를 때의 검색

쇼핑 앱의 검색 경험을 살펴보며, 이름을 모르는 상품은 사진이 있어도 특징을 검색어로 옮기기 어렵다는 문제에 주목했습니다. 사진이나 자연어 설명을 검색 입력으로 쓸 수 있도록, 두 입력을 같은 방식으로 비교할 기준 모델과 평가 흐름을 설계했습니다.

구현 과정

  • 이미지와 텍스트의 공통 표현. 사전 학습된 CLIP (Contrastive Language–Image Pre-training) 모델을 PyTorch에서 불러와 이미지와 텍스트를 같은 벡터 공간의 정규화된 임베딩으로 변환하도록 구현했습니다.
  • 상품 검색 화면. React로 이미지 업로드와 유사 상품 목록 화면을 만들고, 예시 데이터로 검색 결과를 보여주는 방식을 구체화했습니다.
  • 모델 평가 화면. 기준 모델과 개선 후보의 검색 정확도와 응답 시간을 나란히 보고, 성공·실패 사례를 검토할 수 있도록 화면을 설계했습니다.

프로토타입에서 구현한 범위

이미지와 텍스트의 임베딩을 생성하는 기준 모델을 구현하고, 예시 데이터로 상품 검색 결과와 모델 평가 화면을 구성했습니다. 국내 쇼핑몰 데이터 연동, fine-tuning, 실제 검색 품질 측정은 후속 단계입니다.
