해결하려는 문제

실제 서비스 중인 애플리케이션의 검색 경험을 분석하고, 이미지나 자연어만으로 원하는 상품을 찾는 서비스를 직접 설계했습니다. 한국의 쇼핑 서비스에서 활용할 수 있는 검색 품질을 목표로 데이터 수집부터 모델 개선까지 구현했습니다.

구현 과정

  • 이미지와 텍스트를 연결하는 검색. OpenAI의 CLIP (Contrastive Language–Image Pre-training) 모델과 Vector Embedding을 활용해 이미지·자연어 기반 상품 검색을 구성했습니다.
  • 도메인에 맞춘 모델 개선. 사전 학습된 모델만으로 목표한 검색 성능을 얻기 어려워 fine-tuning 과정을 추가했습니다. 쇼핑몰 crawling pipeline을 구축해 학습과 검색에 필요한 데이터셋을 확보했습니다.
  • 반복 가능한 평가 과정. 평가와 실패 분석 pipeline을 구현해 검색 결과를 점검하고, 모델 성능을 지속적으로 개선할 수 있는 작업 흐름을 마련했습니다.

결과와 배운 점

Computer Vision을 실제 검색 서비스에 적용하며 데이터 수집, 모델 fine-tuning, 검색, 평가를 연결했습니다. 모델을 사용하는 데서 나아가 검색 실패를 분석하고 개선하는 과정까지 경험했습니다.
