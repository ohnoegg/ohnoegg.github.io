Commerce Vision Search Engine

이미지와 자연어로 상품을 찾기 위한 검색 프로토타입

담당검색 흐름 설계 · 임베딩 구현 · 검색 및 모델 평가 화면 개발

서비스 · 링크 미등록 GitHub · 링크 미등록

상황

쇼핑 앱에서 상품명을 모르면 사진을 갖고 있어도 색상이나 형태를 검색어로 옮기기 어렵습니다. 사진과 텍스트로 표현한 특징을 함께 비교할 수 있는 검색 방식이 필요했습니다.

과제

개인 프로젝트로 상품 사진과 자연어 설명을 비교할 수 있는 기준 모델을 연결하고, 상품 검색 결과와 모델별 차이를 살펴볼 수 있는 화면을 구현하기로 했습니다.

실행

  • 이미지와 텍스트 임베딩. 사전 학습된 CLIP (Contrastive Language–Image Pre-training) 모델을 PyTorch로 불러와 사진과 설명을 같은 벡터 공간에 매핑했습니다. 변환한 벡터는 정규화해 코사인 유사도로 비교했습니다.
  • 검색과 평가 화면. React로 이미지 업로드와 유사 상품 목록을 만들었습니다. 모델 평가 화면은 예시 데이터로 정확도, 응답 시간, 성공·실패 사례를 비교할 수 있게 구성했습니다.

결과

예제 사진 1장과 영문 설명 3개에서 각각 512차원 임베딩을 생성했습니다. 빨간 스니커즈 사진과의 코사인 유사도는 ‘빨간 스니커즈’ 0.270, ‘파란 스니커즈’ 0.211, ‘검은 우산’ 0.081 순이었습니다. 국내 쇼핑몰 데이터 연동과 검색 정확도 평가는 후속 단계입니다.
