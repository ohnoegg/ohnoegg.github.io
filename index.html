해결하려는 문제

병원을 고를 때 위치, 진료과, 운영시간을 여러 곳에서 확인하고 직접 비교해야 하는 불편에 주목했습니다. 사용자가 원하는 조건을 자연어로 전달하면, 그 조건에 맞는 병원 정보를 탐색할 수 있도록 기획했습니다.

구현 과정

  • 검색에 필요한 데이터 확보. 공공의료데이터를 활용해 전국 병원 데이터를 확보하고, 병원 정보를 검색하는 backend service와 연결했습니다.
  • 자연어 요청과 검색 기능 연결. LangChain 기반 에이전트가 사용자 요청의 조건을 해석하고, Tool Calling으로 backend의 API (Application Programming Interface)를 호출하는 흐름을 구성했습니다.
  • 검색 결과를 활용한 응답. 조회한 병원 정보를 LLM (Large Language Model)의 context로 전달해, 검색 결과를 바탕으로 구조화된 답변을 제공하는 흐름을 설계했습니다.

결과와 배운 점

웹, 서버, 데이터베이스, 에이전트에 이르는 서비스 전반을 직접 구현하고 배포했습니다. 자연어 interface와 실제 데이터 검색 기능을 연결하며 Full-stack 서비스 구현 경험을 쌓았습니다.

해결하려는 문제

실제 서비스 중인 애플리케이션의 검색 경험을 분석하고, 이미지나 자연어만으로 원하는 상품을 찾는 서비스를 직접 설계했습니다. 한국의 쇼핑 서비스에서 활용할 수 있는 검색 품질을 목표로 데이터 수집부터 모델 개선까지 구현했습니다.

구현 과정

  • 이미지와 텍스트를 연결하는 검색. OpenAI의 CLIP (Contrastive Language–Image Pre-training) 모델과 Vector Embedding을 활용해 이미지·자연어 기반 상품 검색을 구성했습니다.
  • 도메인에 맞춘 모델 개선. 사전 학습된 모델만으로 목표한 검색 성능을 얻기 어려워 fine-tuning 과정을 추가했습니다. 쇼핑몰 crawling pipeline을 구축해 학습과 검색에 필요한 데이터셋을 확보했습니다.
  • 반복 가능한 평가 과정. 평가와 실패 분석 pipeline을 구현해 검색 결과를 점검하고, 모델 성능을 지속적으로 개선할 수 있는 작업 흐름을 마련했습니다.

결과와 배운 점

Computer Vision을 실제 검색 서비스에 적용하며 데이터 수집, 모델 fine-tuning, 검색, 평가를 연결했습니다. 모델을 사용하는 데서 나아가 검색 실패를 분석하고 개선하는 과정까지 경험했습니다.

해결하려는 문제

화훼 상품을 구매할 때 매장 정보가 소셜 미디어와 지도 앱 등 여러 채널에 흩어져 있어 탐색 비용이 커지는 문제를 발견했습니다. 매장 정보를 한곳에 연결하고, 에이전트 기반 interface로 탐색 경험을 개선하고자 했습니다.

담당 역할과 구현 과정

  • 기획과 팀 리딩. 3인 팀의 리더로 요구사항과 일정을 관리했습니다. 개발 기준을 공유하고 각자의 작업이 연결되는 부분을 조율하며 서비스 구현을 이끌었습니다.
  • 전국 단위 매장 정보 활용. 공공데이터포털의 소상공인 데이터셋을 확보하고, 매장의 위치와 상세 정보를 서비스 탐색에 활용했습니다.
  • 에이전트와 backend 연계. LangChain을 기반으로 Tool Calling과 MCP (Model Context Protocol)를 활용하는 서비스 구조를 설계·구현하고, 에이전트를 backend의 API (Application Programming Interface)와 연결했습니다.

경험과 배운 점

에이전트 기능 구현과 팀 운영을 함께 맡으며 기술적인 연결 지점과 협업의 연결 지점을 모두 다뤘습니다. 요구사항을 구체화하고 팀원과 개발 기준을 맞추는 소통·협업 역량을 키웠습니다.
